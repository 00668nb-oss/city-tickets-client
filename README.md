# CityTickets – לקוח (React + Vite)

לקוח לאתר הזמנת הכרטיסים לאירועים עירוניים. מדבר עם השרת ב-repository `city-tickets-server`.

## כתובות חיות

| רכיב | כתובת |
|---|---|
| אתר (לקוח) | <https://citytickets-client.onrender.com> |
| שרת (API) | <https://citytickets-api.onrender.com> |
| תיעוד Swagger | <https://citytickets-api.onrender.com/swagger> |
| repository של השרת (ההסבר המלא) | <https://github.com/00668nb-oss/city-tickets-server> |

> **שימו לב:** השרת מאוחסן בשכבה החינמית של Render, ו"נרדם" אחרי כמה דקות ללא בקשות.
> הטעינה הראשונה אחרי שינה עשויה לקחת כדקה. זו התנהגות צפויה ולא תקלה.

## מסכים

- **רשימת אירועים** – חיפוש, סינון לפי קטגוריה ותגית, ודפדוף עם הכפתורים "הקודם" ו"הבא" (הדפדוף נעשה בשרת).
- **אירוע** – רשימת מועדים עם מקומות פנויים, בחירת כמות (1 עד 10) וכפתור קנייה.
  אם מישהי אחרת קנתה את המקומות בינתיים, השרת מחזיר 409; מוצגת ההודעה "הכרטיסים נתפסו על ידי משתמשת אחרת" והמקומות הפנויים מתרעננים.
- **התחברות והרשמה** – ה-token נשמר ב-`localStorage`.
- **ההזמנות שלי** – רשימה עם ביטול הזמנה.

כל התקשורת עם השרת עוברת דרך `src/api.js`: כתובת בסיס, header של `Authorization`, וטיפול מרוכז ב-401 (ניקוי ה-token והפניה להתחברות) וב-409 (`ApiError.isConflict`).

## הרצה

```bash
npm install
cp .env.example .env.local   # אם השרת לא רץ על http://localhost:5196
npm run dev                  # http://localhost:5173
```

השרת צריך לרוץ (ראי ה-README שלו). הכתובת `http://localhost:5173` כבר מותרת ב-CORS שלו; לפריסה יש להוסיף שם את כתובת הלקוח.

| פקודה | מה עושה |
|---|---|
| `npm run dev` | שרת פיתוח |
| `npm run build` | בנייה ל-`dist/` |
| `npm run lint` | בדיקת קוד |

## הדגמת התחרות

פתחי שני דפדפנים (או חלון רגיל וחלון incognito), התחברי בכל אחד מהם כמשתמשת אחרת, והיכנסי לאירוע "סדנת קרמיקה". במועד השני נשאר מקום אחד.
לחצי "קנייה" בשניהם בו-זמנית: אחד מצליח, והשני רואה את הודעת ה-409.

## פריסה ל-Render

הלקוח נפרס כ-Static Site (קובץ `render.yaml` מוגדר). `VITE_API_URL` נקרא בזמן הבנייה, ולכן אחרי שינוי שלו צריך לבנות מחדש (Manual Deploy). בקובץ יש גם כלל rewrite ל-`index.html`, כך שרענון בכתובת כמו `/orders` לא מחזיר 404.
